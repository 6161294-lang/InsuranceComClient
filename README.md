# Insurance Claims Client – לקוח React

לקוח פשוט (React + Vite) לשרת `insurance-claims-server`. יש בו ארבעה מסכים:

1. **התחברות**. ה-JWT נשמר ב-`sessionStorage` ונשלח בכותרת `Authorization: Bearer ...` בכל בקשה.
2. **הרשמה** של שמאי חדש, עם בחירת תחומי התמחות.
3. **רשימת תביעות פתוחות** עם עימוד אמיתי מול השרת (`page` / `pageSize`), וכפתור **"קח לטיפול"** על כל תביעה. בלשונית "בטיפולי" השמאי יכול לאשר, לדחות או לשחרר תביעה.
4. **הודעת התנגשות (409)**: כשעובד אחר לקח את התביעה קודם, נפתחת הודעה ברורה ("התביעה נלקחה לטיפול על ידי עובד אחר") והרשימה מתרעננת.

## הרצה

דרישות: Node.js 20 ומעלה, והשרת רץ על `http://localhost:5080` (ראו README של השרת).

```bash
npm install
```

```bash
npm run dev
```

הלקוח עולה ב-`http://localhost:5173`. שרת הפיתוח של Vite מעביר (proxy) כל בקשת `/api` לשרת, ולכן אין צורך בהגדרת CORS. כדי לשנות את כתובת השרת, מעתיקים את `.env.example` ל-`.env` ומעדכנים את `API_PROXY_TARGET`.

## הדגמת התחרות

1. מתחברים כ-`adjuster1` / `Adjuster123!` בדפדפן אחד.
2. מתחברים כ-`adjuster2` / `Adjuster123!` בדפדפן אחר, או בלשונית אחרת (ה-Token נשמר לכל לשונית בנפרד).
3. בשניהם מוצגת אותה תביעת רכב פתוחה. לוחצים "קח לטיפול" בשניהם.
4. הראשון מקבל "התביעה נלקחה לטיפולך", והשני מקבל את הודעת ה-409.

## Build

```bash
npm run build
```
